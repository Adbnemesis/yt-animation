All use `CPUParticles2D` (deterministic for Movie Maker rendering) with `one_shot = true`, `emitting = false` — trigger via `restart()` / set `emitting = true`. The four single-emitter scenes are plain `CPUParticles2D` roots; `vfx_small_explosion.tscn` is a composite driven by `scripts/vfx/vfx_one_shot.gd` (auto-plays, auto-frees, exported `tint`). All are independent of any character.

## Usage guidelines

- **Foliage silhouettes are white** — tint in Godot via `modulate` (e.g. green grass, autumn leaves, night-dark bushes).
- **Light masks** → use as `LightOccluder2D`-free `PointLight2D.texture` or additive `Sprite2D` overlays.
- **Terrain tiles** are 128px-compatible PAD tiles; use `TileSet` or stacked `Sprite2D`.
- **Overlays** (`util_gradient_dark`, `util_vignette`, `util_gradient_fog`) are full-screen `CanvasLayer` sprites for mood grading.
- Keep paper-cutout consistency: prefer flat assets, `filter` off is NOT needed (art is high-res), avoid mixing with painterly/3D assets.
